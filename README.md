## rgeoamb: Base para análise ambiental em R

rgeoamb é um pacote experimental R para análises ambientais. 

#### For instalation:
``` R
install.packages('remotes')
library(remotes)
remotes::install_github("marquesfilhojp/rgeoamb")
library(rgeoamb)

```
